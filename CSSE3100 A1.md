>The	greatest	common	divisor	of	two	positive	integers	is	the	largest	number	which	divides	into	them	both	evenly,	i.e.,	with	a	remainder	of	0.	For	example,	the	greatest	common	divisor	of	9	and	12	is	3,	and	the	greatest	common	divisor	of	15	and	30	is	15.
>
>Let	$\operatorname{gcd}(a,	b)$	denote	the	greatest	common	divisor	of	positive	integers	$a$	and	$b$,	i.e.,	$a \ge 0$ and $b \ge 0$.	The	following	are	properties	of	$\operatorname{gcd}(a,b)$:
>1. $\operatorname{gcd}(a,	0)	=	a$.
>2. $\operatorname{gcd}(a,	a)	=	a$.
>3.  $\operatorname{gcd}(a,b) = \operatorname{gcd}(b,a)$.
>4.  $b	>	0	\implies	\operatorname{gcd}(a,b)	=	\operatorname{gcd}(b,a \bmod b)$.

## Andy's GCD1
```cpp
method GCD1(a: int, b: int) returns (r: int) {

        r := GCD1(b, a);
    } else if (a % b == 0) {

```
Andy claims this works provided $a, b\ne 0$. With this in mind, we claim that the precondition is $a> 0 \wedge b > 0$ and the postcondition is $r = \operatorname{gcd}(a,b)$ assuming the function is correct.

Below is the backwards reasoning to find a weakest precondition given the pre- and postconditions.

```cpp
method GCD1(a: int, b: int) returns (r: int)
    requires a > 0 && b > 0
    ensures r == gcd(a,b)
{ 
    { (see below) }
    { (a < b ==> b > 0 && a > 0)
        && (a >= b ==> a % b == 0 ==> b == gcd(a,b)) 
        && (a >= b ==> a % b != 0 ==> 
            b > 0 && a % b > 0 && gcd(b, a % b) == gcd(a, b)) }

    if a < b { 
        { b > 0 && a > 0 && true }
        { b > 0 && a > 0 
            && gcd(b, a) == gcd(a, b) }
        { b > 0 && a > 0 
            && forall r' :: r' == gcd(b, a) ==> r' == gcd(a, b) }
        
        r := GCD1(b, a); 
        
        { r == gcd(a,b) }
    } else if (a % b == 0) { 
        { b == gcd(a,b) }
        
        r := b; 
        
        { r == gcd(a,b) }
    } else { 
        { b > 0 && a % b > 0 
            && gcd(b, a % b) == gcd(a, b) }
        { b > 0 && a % b > 0 
            && forall r' :: r' == gcd(b, a % b) ==> r' == gcd(a, b) }
            
        r := GCD1(b, a % b); 
        
        { r == gcd(a,b) }
    } 
    
    { r == gcd(a,b) }
}
```

At the top of the if statement, we have the weakest precondition:
```cpp
{ (a < b ==> b > 0 && a > 0)
        && (a >= b ==> a % b == 0 ==> b == gcd(a,b)) 
        && (a >= b ==> a % b != 0 ==> 
            b > 0 && a % b > 0 && gcd(b, a % b) == gcd(a, b)) }
```
We will show that the method precondition of $a > 0 \wedge b> 0$ implies this precondition, using the given $\operatorname*{gcd}$ properties. We split the weakest precondition into 
```cpp
{ (1) && (2) && (3) }
```
where
```cpp
(1): a < b ==> b > 0 && a > 0
(2): a >= b && a % b == 0 ==> b == gcd(a,b)
(3): a >= b && a % b != 0 ==> b > 0 && a % b > 0 && gcd(b, a % b) == gcd(a, b)
```
Recall that the method precondition is $P\iff a > 0 \wedge b > 0$.

First, $P \implies (1)$ holds because 
```cpp
a > 0 && b > 0 ==> a < b ==> b > 0 && a > 0
<==>
(a > 0 && b > 0 && a < b) ==> b > 0 && a > 0
<==>
a <= 0 || b <= 0 || a >= b || (b > 0 && a > 0)
<==>
!(a > 0 && b > 0) || a >= b || (b > 0 && a > 0)
<==>
true
```
Above, we used the property that $A \implies B \implies C \iff (A \wedge B) \implies C$ and also De Morgan's laws to show that the precondition implies (1).

For (2), 
```cpp
a > 0 && b > 0 ==> (a >= b ==> a % b == 0 ==> b == gcd(a, b))
<==>
(a > 0 && b > 0 && a >= b && a % b == 0) ==> b == gcd(a, b)
<==>
(a > 0 && b > 0 && a >= b && a % b == 0) ==> b == gcd(b, a % b)
<==>
(a > 0 && b > 0 && a >= b && a % b == 0) ==> b == gcd(b, 0)
<==>
(a > 0 && b > 0 && a >= b && a % b == 0) ==> true
<==>
true
```
Here, we used $A \implies B \implies C \iff (A \wedge B) \implies C$, then rule 4 because $b > 0$, replaced $a \bmod b$ with $0$ in the consequent because $a \bmod b = 0$ is in the antecedent, then used rule 1 which is true. Finally, $A \implies \text{true}$ is true so (2) holds with the given precondition.

Finally, we show that the precondition implies (3). 
```cpp
(a > 0 && b > 0) ==> a >= b && a % b != 0 
    ==> b > 0 && a % b > 0 && gcd(b, a % b) == gcd(a, b)
<==>
(a > 0 && b > 0 && a >= b && a % b != 0)
    ==> b > 0 && a % b > 0 && gcd(b, a % b) == gcd(a, b)
<==>
(a > 0 && b > 0 && a >= b && a % b != 0)
    ==> gcd(b, a % b) == gcd(a, b)
<==>
(a > 0 && b > 0 && a >= b && a % b != 0)
    ==> true
<==>
true    
```
Here, we use the repeated implication rule again. To get the third line, we see that $b > 0 \wedge a \bmod b > 0$ is surely true given the antecedent. The next line is because $\operatorname*{gcd}(b, a \bmod b) = \operatorname*{gcd}(a,b)$ is true given $b > 0$. Therefore, $P \implies (3)$.
 
 Therefore, we have proven that 
$$
P \implies (1) \wedge (2) \wedge (3). 
$$
This means that if the method terminates, then it is correct according to the preconditions and postconditions defined.
 
 ### Termination metric
 It remains to show that the method does, in fact, terminate. We can do this with a decreasing termination metric. We claim the lexicographic tuple metric $(b,a)$ is sufficient.
 
 GCD1 has two possible recursive calls. First, if $a < b$ it calls $\operatorname*{GCD1}(b, a)$. Here, the initial metric is $(b,a)$ and the subcall's metric will be $(a,b)$ and $(a, b) \prec (b, a)$ since $a < b$.
 
 The other recursive call is if $a \ge b$ and $a \bmod b \ne 0$, it will call $\operatorname*{GCD1}(b, a \bmod b)$. The initial metric is $(b,a)$ and the subcall metric is $(a \bmod b, b)$. Note that $0 < a \bmod b < b$ by definition of modulus  and given $a \bmod b \ne 0$, so $(a \bmod b, b) \prec (b, a)$.
 
 With this metric in mind, we can see that eventually we will reach a case where the metric is $(1, x)$ corresponding to a call of the form $\operatorname*{GCD1}(x, 1)$ which will not recurse because $x \bmod 1 = 0$ for all $x$. Therefore, $\operatorname*{GCD1}(a,b)$ terminates for all $a,b > 0$.
 
 
 ### Correctness
 With this in mind, we have shown that Andy's GCD1 is totally correct because it satisfies the pre- and postconditions and terminates.


## Candy's GCD2

```cpp
method GCD2(a: int, b: int) returns (r: int) {
    if b == 0 {
        r := a;
    } else {
        r := GCD2(b, a % b);
    }
}
```
Candy claims this works for non-negative $a,b$ so we will use a precondition of $a \ge 0 \wedge b \ge 0$. The postcondition of this is, of course, $r = \operatorname{gcd}(a,b)$.

With this in mind, we will use backwards reasoning.
```cpp
method GCD2(a: int, b: int) returns (r: int)
    requires a >= 0 && b >= 0
    ensures r == gcd(a, b)
{
    { (b == 0 ==> a == gcd(a, b))
        && (b != 0 ==> 
            b >= 0 && a % b >= 0 && gcd(b, a % b) == gcd(a, b))}
    if b == 0 {
        { a == gcd(a, b) }
        r := a;
        { r == gcd(a, b) }
    } else {
        { b >= 0 && a % b >= 0 
            && gcd(b, a % b) == gcd(a, b) }
        { b >= 0 && a % b >= 0 
            && forall r' :: r' == gcd(b, a % b) ==> r' == gcd(a, b) }
        r := GCD2(b, a % b);
        { r == gcd(a, b) }
    }
    { r == gcd(a, b) }
}

```

Let the weakest precondition be $(1) \wedge (2)$ where
```cpp
(1): b == 0 ==> a == gcd(a, b)
(2): b != 0 ==> b >= 0 && a % b >= 0 && gcd(b, a % b) == gcd(a, b)
```
Now, we need to show that the precondition of $a \ge 0 \wedge b \ge 0$, which we will call $P$, implies $(1) \wedge (2)$. 

Note that (1) is a true statement by the one point rule, we can write
```cpp
b == 0 ==> a == gcd(a, b) 
<==>
a == gcd(a, 0)
<==>
```
which is true by rule 1.

For (2):
```cpp
(a >= 0 && b >= 0) ==> b != 0 
    ==> b >= 0 && a % b >= 0 && gcd(b, a % b) == gcd(a, b)
<==>
(a >= 0 && b >= 0 && b != 0)
    ==> b >= 0 && a % b >= 0 && gcd(b, a % b) == gcd(a, b)
<==>
(a >= 0 && b >= 0 && b != 0)
    ==> a % b >= 0 && gcd(b, a % b) == gcd(a, b)
<==>
(a >= 0 && b >= 0 && b != 0)
    ==> gcd(b, a % b) == gcd(a, b)
<==>
(a >= 0 && b >= 0 && b != 0) ==> true
<==>
true
```
Here, we reduced the implications, then removed $b \ge 0$ from the consequent because it is in the antecedent. Then, $a \bmod b \ge 0$ is always true by properties of $\bmod$ and $b \ne 0$. Finally, given $b > 0$, we have $\operatorname*{gcd}(b, a \bmod b) = \operatorname*{gcd}(a, b)$ which reduces the consequent to true and the entire implication holds.

Therefore, the method preconditions imply the weakest needed precondition. This proves partial correctness.

### Termination metric

We claim that the tuple metric $(b, a)$ is sufficient. There is only one recursive call here. The subcall has metric $(a \bmod b, b)$ if $b > 0$. Because $a \bmod b < b$, this metric will monotonically decrease.

This proves it will always reach a base case of $\operatorname*{GCD2}(a, 0)$ with metric $(0, a)$ and so it always terminates.

### Correctness

With the proof of partial correctness and proof of termination, we see that Candy's GCD2 is a totally correct method.
