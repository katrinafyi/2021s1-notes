The following is a tail-recursive definition for the exponential function that **counts down**

```haskell
expDown :: Int -> Int -> Int
expDown x y = h_exp x y 1

h_exp :: Int -> Int -> Int -> Int
h_exp x 0 ans = ans
h_exp x y ans = h_exp x (y-1) (ans*x)
```

A) Give the tail-recursive definition for `expUp` \-- an implementation of the exponential function that **counts up**. You may presume $n\ge0$. \[3 points\]

```haskell
-- | expUp x y computes x^y.
expUp :: Int -> Int -> Int
expUp x y = h_expUp x y 0 1
    where h_expUp :: Int -> Int -> Int -> Int -> Int
          h_expUp x y n r
            | n == y = r
            | otherwise = h_expUp x y (n+1) (x*r)
```

B) Find the **iteration invariant** for your function and prove each line of your code satisfies it. \[4 points\]

Assuming $0 \le n \le y$, the iteration invariant is:
```haskell
h_expUp x y n r == r * x^(y-n)
```

For the guard where $n=y$, we have:
```haskell
LHS 1 = h_expUp x y n r = r * x^(y-n) = r * x^0 = r
RHS 1 = r
```
For the otherwise where $n < y$, we have:
```haskell
LHS 2 = h_expUp x y n r = r * x^(y-n)
RHS 2 = h_expUp x y (n+1) (x*r)
      = (x*r) * x^(y-(n+1))    -- invariant for recursive call
      = r * x^(y - (n+1) + 1)  -- move x* into power
      = r * x^(y-n)            -- simplify
```
Therefore, the iteration invariant holds for both cases of `h_expUp`.

C) Use your invariant to prove the correctness of `expUp`. \[2 points\]

Supposing that we have `h_expUp x y n r == r * x^(y-n)`, we can show that expUp is correct because
```haskell
expUp x y = h_expUp x y 0 1 = r * x^(y-n) = 1 * x^(y-0) = x^y
```
so `expUp x y` correctly calculates $x^y$.

D) State the **bound value** for this program. \[1 points\]

The bound value for `h_expUp` is $y-n$ which starts at $y-0=y$ and decreases to $y-y=0$ as it recurses to the base case.
