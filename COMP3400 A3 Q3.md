## Property-based tests
Assume that we can generate arbitrary trees.
```haskell
-- maxPath of leaf should be the leaf's value.
prop_maxPath1 = \x -> maxPath (Leaf x) == x
-- maxPath of Node should be greater or equal to maxPath of both
-- subtrees and greater or equal to its own node value.
prop_stackFoldl2 = \t1 t2 x -> 
  maxPath (Node t1 x t2) >= maximum [x, maxPath t1, maxPath t2]
```

## Unit tests
Define the following trees:
```haskell
{-
       30
      /  \
    90    90
    / \   / \
 -300 0   0 -300
 /  \    /   \
150  0  0    150
-}
t1 = Node 
  (Node (Node (Leaf 150) (-300) (Leaf 0)) 90 (Leaf 0)) 
  30 
  (Node (Leaf 0) 90 (Node (Leaf 0) (-300) (Leaf 150)))
  
  
{-
   -1000
   /   \
500    400
-}
t2 = Node (Leaf 500) (-1000) (Leaf 400)
```

Then, the tests are:
```haskell
describe "maxPath" $ do
  it "works" $ do
    maxPath t1 `shouldBe` 210
    maxPath t2 `shouldBe` 500
```
- t1 checks that a path from the root can be considered and avoids negative branches if they would reduce the max path.
- t2 checks that a path not starting at the root can be chosen if the root is negative.
