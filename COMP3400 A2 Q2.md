# COMP3400 A2 Q2
### Kait Lam
Define a function `iter` such that for all $n \ge 0$ and any `f :: a -> a`

```
iter n f
```

is the $n$\-fold composition of $f$ with itself, i.e. $f \circ f \circ\cdots\circ f$, $n$\-times.

```haskell
iter :: Integer -> (a -> a) -> (a -> a)
iter 0 _ = id
iter n f = f . iter (n-1) f
```
Assuming precondition $n \ge 0$ and so negative $n$ is undefined.
