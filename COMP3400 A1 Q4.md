**Claim.** A $2^n\times 2^n$ Blockus board with one corner removed can be covered with V3 pieces.

**Proof.** We will prove this using induction. First, the base case of $2^0 \times 2^0$ is trivially true. This board would be $1 \times 1$ and with a corner removed can be tiled with zerospo V3 tiles. 

Assume the predicate holds for $2^k\times 2^k$ boards, and we will show it holds for $2^{k+1} \times 2^{k+1}$ boards. Given a $2^{k+1} \times 2^{k+1}$ board, we can split it into 4 quadrants, each of size $2^{k} \times 2^{k}$. Using the inductive hypothesis, we can fill a $2^k \times 2^k$ square with V3 tiles except for one corner. 

Arrange the quadrants such that the top left one has a missing corner in the top left, and the other 3 quadrants have missing corners towards the centre of the $2^{k+1} \times 2^{k+1}$ board. For the case of $2^2 \times 2^2$, it looks like this:

We can fill the middle with one more V3 tile, successfully tiling a board of size $2^{k+1}\times 2^{k+1}$.

We have shown that we can tile boards of size $2^0\times 2^0$. Moreover, if we can tile a board of size $2^k \times 2^k$, then we can tile a board of size $2^{k+1} \times 2^{k+1}$. By the principle of mathematical induction, we can tile any $2^{n}\times 2^n$ except for one corner, for all $n \in \mathbb N$.
