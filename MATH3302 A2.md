## Question 2
> Use Friedman’s method 1 to verify that it is likely that the following text is ciphertext arising from encryption using a Vigenere cipher with $m = 13$. 

Friedman's method allows us to deduce a value for $m$, the block size. To do this, we guess a value for $m$ then verify it by arranging the ciphertext into columns of length $m$ and compute the index of coincidence down each column. We then average the indices across the columns. 

If the $m$ is the key length, this averaged index should be close to 0.065. We did this for values of $m = 2, \ldots, 20$. We can see that 13 is much closer to 0.065 than the other values so $m=13$ is the most likely value.

## Question 3
> Assume that $K$ is a valid key for use in a Hill cipher, with $m = 2$. Define double encryption using the Hill cipher, where the same key $K$ is used twice, as
> $$
> \begin{aligned}
> K &= \begin{bmatrix}a & b \\ c & d \end{bmatrix} \\
> \begin{bmatrix} G & H \end{bmatrix} &= e_K(e_K(\begin{bmatrix} g & h \end{bmatrix})) \\ 
> &= \left(\begin{bmatrix} g & h \end{bmatrix} \begin{bmatrix}a & b \\ c & d \end{bmatrix}\right)\begin{bmatrix}a & b \\ c & d \end{bmatrix}.
> \end{aligned}
> $$

### Question 3.a
>  Show that double encryption is a valid encryption algorithm, that is, show that if $Y = e_K(x)$ is the ciphertext then there exists a decryption key $K'$, such that, $x = e_{K'}(Y)$. Does double encryption increase security?

If $Y$ is the result of encrypting $x$ with the double Hill cipher and key $k$, then $K' = K^{-1}$ can be used to decrypt the ciphertext.
$$
\begin{aligned}
Y& = e_K(x) = (xK)K \\
\implies x &= e_{K^{-1}}(Y) = (YK^{-1})K^{-1} = (((xK)K)K^{-1})K^{-1}=x
\end{aligned}
$$
Above, we use the associativity of matrix multiplication.

Double encryption does not increase security here because double encryption with a key $K$ is *exactly the same* as a single Hill cipher with key $K^2$. This can be seen from
$$
Y = e_K(x) =(xK)K = x(KK) = xK^2.
$$
Because $K$ is invertible, then $K^2$ is invertible so $K^2$ is also a valid key for the ordinary Hill cipher. This can be shown be using the fact that  $\det A \ne 0$ and $\det B  \ne 0$ implies $\det (AB) = \det A \det B \ne 0$.

### Question 3.b
> Repeat part (i) but this time assume there are two distinct valid keys, say matrices $K_1$ and $K_2$ for a Hill cipher, and this time double encrypt but first encrypting with $K_1$ and then encrypting with $K_2$. Is this still a valid encryption algorithm? Will the security be increased if the second key is different?

We can encrypt like so
$$
Y = e_{K_1, K_2}(x) = xK_1K_2
$$
where $K_1$ and $K_2$ are invertible. Then, we can decrypt using keys $K_1^{-1}$ and $K_2^{-1}$ with
$$
\begin{aligned}
e_{K_2^{-1}, K_1^{-1}}(Y) = YK_2^{-1}K_1^{-1} &= 
xK_1K_2K_2^{-1}K_1^{-1} \\ 
&= x(K_1(K_2K_2^{-1})K_1^{-1})\\
&= x.
\end{aligned}
$$
Therefore, this is a valid encryption algorithm.

Unfortunately, this still does not increase security because it is equivalent to a single Hill cipher with key $K= K_1K_2$ since $K_1$ and $K_2$ are invertible, their product is as well.


## Question 4

> Let $m$ be a fixed positive integer and $\pi$ a permutation on the set $\{1, \ldots, m\}$. Define the row transportation cipher as a cipher with encryption function 
> $$
> \begin{aligned}
> e_K(x) = e_\pi(x) = e_\pi(x_1, x_2,\ldots, x_m) = (x_{\pi^{-1}(1)}, x_{\pi^{-1}(2)}, \ldots, x_{\pi^{-1}(m)}).
> \end{aligned}
> $$
> Show that this row transposition cipher is a special case of the Hill cipher.

This is the case because we can write row transposition as multiplication by a permutation matrix. That is, a matrix $P$ with exactly one $1$ in each row and in each column.

Consider encrypting a message with the Hill cipher where we write the columns of $K$ as column vectors $v_1, \ldots, v_m \in \mathbb Z_{26}^m$.
$$
e_K(x) = xK = x\begin{bmatrix}
| & & | \\
v_1  & \cdots & v_m\\
| &  & | 
\end{bmatrix}
= 
\begin{bmatrix}
xv_1 & xv_2 & \cdots & xv_m
\end{bmatrix}.
$$
Let $\pi : \{1, \ldots, m\} \to \{1, \ldots, m\}$ be a permutation of the indices and let $\pi^{-1}$ be its inverse. With this in mind, we can choose $v_i$ as the vector with one $1$ in the $\pi^{-1}(i)$-th position and zero elsewhere. Then, this can be used to select the $\pi^{-1}(i)$-th component in a vector $x$
$$
xe_{\pi^{-1}(i)}=0x_1 + \cdots + 1x_{\pi^{-1}(i)} + \cdots + 0x_m = x_{\pi^{-1}(i)}.
$$

Let the key matrix $K=P$ be 
$$
P = \begin{bmatrix}
| &  & |\\
e_{\pi^{-1}(1)} & \cdots & e_{\pi^{-1}(m)}\\
| &  & |
\end{bmatrix}
$$
and then we can apply this in a Hill cipher to get the encryption function like so
$$
\begin{aligned}
e_P(x) = xP = x\begin{bmatrix}
| &  & |\\
e_{\pi^{-1}(1)} & \cdots & e_{\pi^{-1}(m)}\\
| &  & |
\end{bmatrix}
&= 
\begin{bmatrix}
xe_{\pi^{-1}(1)} & xe_{\pi^{-1}(2)} & \cdots & xe_{\pi^{-1}(m)}
\end{bmatrix} \\ 
&=\begin{bmatrix}
x_{\pi^{-1}(1)} & x_{\pi^{-1}(2)} & \cdots & x_{\pi^{-1}(m)}
\end{bmatrix}.
\end{aligned}
$$
Furthermore, permutation matrices are orthogonal so $P^{-1}$ exists and $P^{-1}=P^\top$. Therefore, $P$ is a valid key for the Hill cipher and we have shown the row transportation cipher is just a special case of the Hill cipher.

charToZ26 :: Char -> Int
charToZ26 = subtract (ord 'A') . ord . toUpper

z26ToChar :: Int -> Char
z26ToChar = chr . (+ ord 'a') . (`mod` 26)

decryptShift xs = decodeLetter <$> xs
  where
    freqs = computeFreqs xs

computePairs :: String -> [(Char, Char)]

indexOfCoincidence :: Fractional a => String -> a
indexOfCoincidence s = fromIntegral numEqual / fromIntegral numPairs
  where
    pairs = computePairs s
    numPairs = length pairs
    numEqual = length . filter (uncurry (==)) $ pairs

chunks :: Int -> [a] -> [a](a)
chunks _ [] = []

minMax :: Ord a => [a] -> (a,a)

average :: (Real a, Fractional b) => [a] -> b

chunkToColumns :: Int -> String -> [String]
