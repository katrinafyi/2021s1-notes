# COMP3400 A2 Q3
### Kait Lam
Given the code

```haskell
foo :: a -> [a] -> a
foo = foldl (curry snd)
```

A) **Very briefly** explain (in English) what `foo` ultimately does. \[2 points\]

`foo a as` takes a value `a` and a list `as`. If the list is not empty, it returns the last element in `as`. If the list is empty, it returns `a`.

B) Provide a more straightforward implementation. \[3 points\]

There are many things we could do. Keeping with a fold, foldl's first argument is of the form `f :: b -> a -> b` where `b` is from folding the list items to the left of the current value, `a`.  

`curry snd` is a function of two arguments which returns its second argument. It is identical to `\_ b -> b` or `const id`. We can use one of these in its place, so
```haskell
foo = foldl (\_ b -> b) -- using more obvious lambda
foo = foldl (const id)  -- using functions
```
However, the foldl itself is unnecessary and obscures the meaning. Since this gets the last item in a list, we can just use that. The "default value" can be implemented by prepending it to the list, like so:
```haskell
foo a as = last (a:as)  -- using list operations.
```
This is functionally equivalent and we can be sure it never throws because the argument to last is always non-empty.
