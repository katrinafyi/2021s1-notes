Consider the following definitions for multiplying Natural numbers.

```haskell
data Nat = Zero | Succ Nat deriving Show

emb :: Nat -> Int
emb Zero     = 0
emb (Succ n) = 1 + emb n

plus :: Nat -> Nat -> Nat
plus n Zero     = n
plus n (Succ m) = plus (Succ n) m

times :: Nat -> Nat -> Nat
times _ Zero = Zero
times n (Succ m) = plus n $ times n m
```

**Claim.** For all natural `n`, `emb (times m n) = emb m * emb n`.

**Proof.** The base case is when `n` is Zero. Then, we have 
```haskell
emb (times m n) = emb (times m Zero) = emb Zero = 0
```
and
```haskell
emb m * emb n = emb m * emb Zero = emb m * 0 = 0
```
so it holds for the base case.

Assume it holds for `k` so `emb (times m k) = emb m * emb k`.

We will show it holds for `Succ k` (since `k` has the type `Nat`). The left hand side is
```haskell
emb (times m (Succ k)) = emb (plus m $ times m k) -- definition of times
                       = emb m + emb (times m k)  -- assuming addition
                       = emb m + emb m * emb k    -- using hypothesis
```
For the right hand side,
```haskell
emb m * emb (Succ k) = emb m * (1 + emb k)
                     = emb m + emb m * emb k  -- distributivity of ints
```
Therefore, it holds for `Succ k`.

We have shown that the predicate holds for `Zero` and if holds for `k` then it holds for `Succ k`. Therefore, it holds for all `k :: Nat` by the principle of mathematical induction (applied here to the type Nat describing Peano numbers). $\square$
